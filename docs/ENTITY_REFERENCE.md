# Entity reference

The integration creates entities for each configured parking facility.

Entity names are based on the parking facility name supplied by the VDL data source. The final entity IDs are generated by Home Assistant and may depend on the selected parking facility and existing entities.

## Sensors

Each parking facility provides four numerical sensors.

| Information | Description |
|---|---|
| Available spaces | Number of parking spaces currently reported as available |
| Total capacity | Total number of parking spaces |
| Occupied spaces | Calculated number of occupied spaces |
| Occupancy rate | Calculated occupancy percentage |

### Available spaces

Represents the number of spaces currently available according to the VDL data.

### Total capacity

Represents the total reported capacity of the parking facility.

### Occupied spaces

Calculated using:

`max(total capacity - available spaces, 0)`

### Occupancy rate

Represents the percentage of the parking facility currently occupied.

The value is calculated from occupied spaces and total capacity. If the reported capacity is zero, the occupancy rate is zero.

## Binary sensors

Each parking facility provides three status entities.

| Information | Description |
|---|---|
| Open | Whether the parking facility is reported as open |
| Full | Whether the parking facility is reported as full |
| Out of service | Whether the parking facility is reported as being affected by a fault or service interruption |

### Open

Reflects the open/closed status supplied by the VDL service.

### Full

Reflects the full status supplied by the VDL service.

### Out of service

Reflects the fault or out-of-service status supplied by the VDL service.

This entity is intended primarily for diagnostic and status purposes.

## Availability and reliability

Entity values depend on successful updates from the VDL endpoint.

If the upstream service is unavailable or returns invalid data, the integration may not be able to refresh the entities. A failed update does not mean that the parking facility has become full or closed.

## Entity IDs

Home Assistant generates entity IDs from the entity names. The exact IDs can vary depending on:

- The parking facility name
- Existing entities in the Home Assistant instance
- Previous entity registry entries
- Changes made by the user in Home Assistant

Use the entity IDs shown in **Settings → Devices & services → Entities** when configuring dashboards or automations.
