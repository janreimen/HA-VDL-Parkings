# Getting Help

## Before asking for help

1. Read the [README](README.md) for installation, configuration and examples.
2. Check the [Troubleshooting](README.md#troubleshooting) section.
3. Check the existing [GitHub issues](https://github.com/janreimen/HA-VDL-Parkings/issues).
4. Confirm that Home Assistant meets the minimum version declared in the integration manifest.

## Report a problem

Open an issue in the [GitHub issue tracker](https://github.com/janreimen/HA-VDL-Parkings/issues) and include:

- Home Assistant Core version.
- VDL Parkings integration version.
- Installation method (HACS or manual).
- What you expected to happen and what happened instead.
- Steps to reproduce the problem.
- Relevant log entries from **Settings → System → Logs**.

Remove access tokens, passwords, personal information and other secrets before sharing logs.

## Feature requests

Describe the use case and expected behaviour. If possible, explain whether the request affects configuration, sensors, zones or data refresh.

## Scope

This project is a community integration, not an official VDL or Home Assistant support channel. VDL controls the source parking data and its availability.
