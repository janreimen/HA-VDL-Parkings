# Security Policy

## Supported versions

Security fixes are intended for the current version of the integration on the repository's default branch. Older revisions may not receive security updates.

## Reporting a vulnerability

Please do not publish exploitable security details in a public issue.

If GitHub's **Private vulnerability reporting** feature is enabled for this repository, use it to submit a report privately. Otherwise, contact the repository maintainer privately through their GitHub profile and request a secure channel.

Include, where possible:

- A clear description of the issue and its potential impact.
- The affected integration version and Home Assistant version.
- Steps to reproduce or a minimal proof of concept.
- Any suggested mitigation.

Please allow reasonable time for investigation and a fix before publicly disclosing the vulnerability.

## Scope

The integration retrieves publicly available parking information from VDL and does not require a VDL account, API key or user credentials.

Reports involving the integration, its handling of upstream responses or its interaction with Home Assistant are in scope.
